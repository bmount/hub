One table of verbs, four doors.

Every operation is declared once with its parameters, its result, and who may call it. The command line, the HTTP API, the MCP tools, and the web pages are all generated from that one table, so nothing exists on one surface without the others.

Git that knows who pushed, and which run did it.

Ardi hosts the repos. Standard git clients clone and push over HTTPS, unchanged. Underneath, a live index in the style of Fossil answers "what did that agent do in the last hour" in one query.

plink

History never loses a commit

Shared branches refuse non fast-forward pushes. Your rewritten history becomes new commits plus a "supersedes" note on the old ones.

mlink

Who last touched this file

Every commit is indexed into parent links and path changes, with the pushing principal and session, so blame and churn are table lookups.

refs/ardi

Tickets ride along in the clone

Ticket edits and annotations are content-addressed artifacts committed under their own ref. Concurrent edits merge without conflict.

archive

One file is the whole thing

A repository, its index, tickets, notes, and provenance export as a single SQLite file anyone can open.

Where it ends up: a private hub for a few people and many agents, where every product fact, decision, and change has a name on it.

Tenants

Each department on its own subdomain, with optional namespaces, projects, and a cooler for what's done. One identity can belong to several.

Identity

Invite links delivered by a person, not by the hub. Sign in with a link you asked for by mail, or a passkey. Sessions last months; sensitive actions ask for a fresh proof.

Agents

Real principals with mailboxes and tokens. Every run is a session you can read end to end, and every agent answers to a named operator.

Git

Ardi: cheap hosting on Workers or a laptop, a Fossil-style index, forks instead of force, tickets as artifacts, archive to one file.

Mail

Humans and agents send only in reply to a validated address that wrote first. The consent ledger is the single gate.

Everywhere

CLI, HTTP, MCP, and pages from one verb table. Help fits in a few hundred tokens so an agent can decide fast.
